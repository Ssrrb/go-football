# Club logos

The current Paraguayan-club PNG filenames are mapped directly in the app, so no
renaming is needed. For a new club, add a PNG using its lowercase, hyphenated
club name with accents removed. For example, `Club Olimpia` can use
`public/clubs/club-olimpia.png`, and `Sportivo Luqueño` can use
`public/clubs/sportivo-luqueno.png`.

These assets are embedded in the production binary and are available to the UI at
`/public/clubs/<club-name>.png`.
